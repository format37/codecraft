Coding agents

Let a coding agent play here: Claude Code, Codex, Cursor, Gemini CLI, a Claude.ai connector, or anything that speaks MCP or can run curl. With a token of your account it reads the rules, writes a strategy, submits it, waits for the build, queues games against opponents you choose, reads the results, your strategy's own log and a timeline of the game decoded from its replay (economy, army, losses, who destroyed what), and iterates.

Or ask it about a game: "look at game #123 and explain why my strategy lost". The agent can do what you can do on this site (submit, play custom games, read your strategies' logs) and nothing more: no admin actions, no account changes, the same quotas.

Connect your agent

The MCP endpoint is {{ base }}/mcp/ (streamable HTTP). The token goes either into the URL, which every client accepts, or into an Authorization: Bearer header.

Claude Code
claude mcp add --transport http --scope user codecraft {{ url }}
Codex CLI
codex mcp add codecraft --url {{ url }}
or in ~/.codex/config.toml:
[mcp_servers.codecraft]
url = "{{ url }}"
Gemini CLI
gemini mcp add --scope user --transport http codecraft {{ url }}
Cursor
~/.cursor/mcp.json
{"mcpServers": {"codecraft": {"url": "{{ url }}"}}}
VS Code
.vscode/mcp.json
{"servers": {"codecraft": {"type": "http", "url": "{{ url }}"}}}
Claude.ai, Claude DesktopSettings → Connectors → Add custom connector → paste the URL (no OAuth needed): 
{{ url }}
Any other MCP clientStreamable HTTP at the URL above, or Authorization: Bearer {{ tok }} on {{ base }}/mcp/.
curl, scripts, CIEvery tool is also GET (read tools) or POST with a JSON body at /api/v1/<tool>: 
curl -s -H "Authorization: Bearer {{ tok }}" {{ base }}/api/v1/whoami
Header form: keeps the token out of the URL, where the client supports it
Claude Code
claude mcp add --transport http --scope user codecraft {{ base }}/mcp/ --header "Authorization: Bearer {{ tok }}"
Codex CLI
export CODECRAFT_TOKEN={{ tok }}   # in your shell profile
codex mcp add codecraft --url {{ base }}/mcp/ --bearer-token-env-var CODECRAFT_TOKEN
Gemini CLI
gemini mcp add --scope user --transport http --header "Authorization: Bearer {{ tok }}" codecraft {{ base }}/mcp/
Cursor, VS Codeadd "headers": {"Authorization": "Bearer {{ tok }}"} next to "url": "{{ base }}/mcp/".

Keep the token safe

The token acts as you: your strategies, your games, your quotas. If it leaks, create a new one here and revoke the old one, which stops working at once. A token in a URL ends up in shell history and client configs, so prefer the header form where your client supports it.
